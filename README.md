# ПСК «МОНОЛИТ»

Сайт промышленно-строительной компании по выбранному и доработанному визуальному макету.

## Локальный запуск

```sh
cd site
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

## Сборка и проверка

```sh
cd site
npm run build
npm test
```

Для сборки под путь GitHub Pages задайте `PAGES_BASE=/psc-monolit/`. Клиентские файлы находятся в `site/dist/client`. GitHub Actions собирает и публикует их при push в `main`.

## Содержание и границы

- Общестроительная специализация, отдельный блок о компании, направления услуг, объекты и контакты.
- Телефон и email взяты с действующего сайта; переход к звонку и подготовка письма работают без серверной формы. Кнопка «Подготовить письмо» создаёт ссылку на черновик в почтовой программе посетителя, не сообщает о состоявшейся отправке и не передаёт данные серверу сайта.
- Фото сгенерированы как иллюстрации направлений, не являются подтверждёнными фотографиями построенных компанией объектов. Для фактического портфолио нужны реальные материалы, разрешённые к публикации.
- Документы открываются с действующего сайта. Актуальность и юридическая действительность файлов не подтверждались.
- Локальные шрифт, логотип, WebP-фотографии и иконки. Без внешней аналитики и провайдеров форм.
- Это отдельная публикация GitHub Pages. Домен `psc-monolit.ru` и DNS не изменяются.

## Дизайн и происхождение ресурсов

Решения записаны в [DESIGN.md](DESIGN.md). Шрифт Manrope распространяется по SIL OFL, иконки Tabler — по MIT; тексты лицензий в `site/licenses/`. Оригинальный знак компании получен с `psc-monolit.ru`. Дизайн и сгенерированные фотографии подготовлены в этом проекте; изображения отмечены как иллюстративные.

Исходные фотографии до WebP-оптимизации: ImageGen outputs `exec-3766ca46-572e-414b-b75a-bcccb9d03983`, `construction_asset`, `noise_asset`. При изменении снимков сохраните подписи об их статусе.
